# Dashboard 真实数据接入清单

> 状态：已实施，保留为历史验收清单（更新于 2026-08-19）。Dashboard 已读取 `erp-api` 真实聚合接口；库存卡继续按原范围留白。当前运行说明以两个项目 README 为准。

## 本阶段范围

- 保留现有首页布局与全部卡片，不删除 UI。
- 接入本地真实数据库：实时销量、销售趋势、顶部筛选、订单分布、销售分布、自发货订单、业绩表现。
- 库存卡继续保留占位展示，不接库存表、库存 API 或同步任务。
- 金额只在同一币种内聚合，不进行推测性汇率换算。

## API 合同

`GET /api/dashboard/snapshot`

查询参数：

- `platform`：平台代码，可空。
- `site`：店铺站点/地区，可空。
- `shopId`：店铺 UUID，可空。
- `currency`：三位币种，默认 `USD`。
- `timezone`：IANA 时区，用于“今日”和趋势分桶。
- `realtimeRange`：`today` 或 `last24h`。
- `trendRange`：`last7d`、`last30d`、`lastMonth` 或 `year`。
- `orderRange`：`last7d`、`last14d` 或 `last28d`。

数据来源：`shops`、`orders`、`order_lines`、`order_recipients`。销售统计排除 `unpaid` 与 `cancelled`；取消订单单独计数。净销售额在退款数据接入前暂按实付金额展示，并在响应中标记为估算口径。

## 验收标准

- 所有查询必须使用登录会话中的 `tenant_id`，店铺筛选不能跨租户。
- 改变平台、站点、店铺、币种或时间范围后，React Query key 改变并重新请求 API。
- 趋势日期和折线点来自 API，不再包含固定日期或固定 SVG 点位。
- 销售分布和订单分布支持空数据、多分类和百分比展示。
- Dashboard 真实模式失败时显示错误页，不回退到 Mock。
- 库存卡仍存在，但不会被误认为真实库存。
